## Questions

1. **Capture resistance** — Can a single commercial entity or single state actor unilaterally set the rules that others must follow?
2. **Token / payment rule-power** — Can money or tokens buy protocol rule changes? (AIC intent: no.)
3. **Inspectability** — Can independent parties inspect decision paths and failure modes?
4. **Human gate** — Are consequential outcomes able to require human judgment?
5. **Succession** — Is continuity addressed without concentrating unaccountable power?
6. **Public communication** — Is maturity under-claimed so that reliance is not misled?
7. **Exit / fork reality** — Can others practically exit or fork if governance degrades?
